MIDI Forge - installation
=========================

Windows (VST3)
--------------
  Copy "MIDI Forge.vst3" to  C:\Program Files\Common Files\VST3\

macOS (VST3, Apple Silicon and Intel)
-------------------------------------
  Copy "MIDI Forge.vst3" to  ~/Library/Audio/Plug-Ins/VST3/

  The plug-in is not notarized by Apple, so macOS quarantines it after the download and the DAW
  refuses to load it. Remove the quarantine flag once, in Terminal:

    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"MIDI Forge.vst3"

Then rescan plug-ins in your DAW.

Using it
--------
  Reaper: put MIDI Forge on a track's FX chain *before* the instrument.
  Bitwig: put MIDI Forge in the Note FX section of an instrument track (or before the instrument).
